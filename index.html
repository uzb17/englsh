Supabase Baza Sozlamalari 100% BEPUL

O‘quvchilar va ma’lumotlarni doimiy bulutli bazada (PostgreSQL) saqlash

⚠️
Baza holati: Lokal rejimda ishlamoqda Hozirda yangi qo‘shilgan o‘quvchilar faqat ushbu brauzerda qoladi. Quyidagi 4 ta oson qadam orqali bepul Supabase bazasini ulasangiz, istalgan o‘quvchi o‘z telefonidan bemalol login qilib kira oladi va ma’lumotlar hech qachon yo‘qolmaydi!
Supabase Dashboard -> Project Settings -> API -> Project URL
Supabase Dashboard -> Project Settings -> API -> Project API Keys (anon public)

📖 Supabase Bazasini Ulash (2 daqiqalik qo‘llanma):

  1. supabase.com ga kiring va bepul ro‘yxatdan o‘ting (Saytga o‘tish).
  2. "New Project" tugmasini bosib yangi loyiha oching (masalan, english-academy). Parolni eslab qoling.
  3. Chap menyudan SQL Editor ga o‘ting, "New query" oching va quyidagi tayyor SQL kodni tashlab, Run tugmasini bosing!
  4. Project Settings -> API bo‘limiga o‘tib, Project URL va anon public key ni ko‘chirib yuqoridagi maydonlarga joylang va "Saqlash" tugmasini bosing.
Supabase SQL Script (Jadvallarni yaratish kodi): 
-- 1. O'quvchilar jadvali (Students)
CREATE TABLE IF NOT EXISTS students (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  level TEXT DEFAULT 'A0',
  xp INTEGER DEFAULT 0,
  streak INTEGER DEFAULT 1,
  total_time_spent_minutes INTEGER DEFAULT 0,
  registered_date TEXT,
  completed_lessons JSONB DEFAULT '[]'::jsonb,
  quiz_scores JSONB DEFAULT '{}'::jsonb,
  starred_words JSONB DEFAULT '[]'::jsonb,
  comprehension_ratings JSONB DEFAULT '{}'::jsonb,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Uy vazifalari jadvali (Homeworks)
CREATE TABLE IF NOT EXISTS homeworks (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  type TEXT NOT NULL,
  category_name TEXT,
  prompt TEXT,
  instructions TEXT,
  created_date TEXT,
  due_date TEXT,
  max_score INTEGER DEFAULT 100,
  assigned_to TEXT DEFAULT 'all',
  assigned_to_name TEXT DEFAULT 'Barcha o‘quvchilar',
  submissions JSONB DEFAULT '[]'::jsonb,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. To'g'ridan-to'g'ri xabarlar jadvali (Chats)
CREATE TABLE IF NOT EXISTS chats (
  id TEXT PRIMARY KEY,
  thread_id TEXT NOT NULL,
  sender_id TEXT NOT NULL,
  sender_name TEXT NOT NULL,
  sender_role TEXT NOT NULL,
  type TEXT DEFAULT 'text',
  text TEXT,
  audio_data_url TEXT,
  audio_duration TEXT,
  file_data_url TEXT,
  file_name TEXT,
  file_size TEXT,
  file_type TEXT,
  timestamp TEXT,
  edited BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. RLS Xavfsizlik siyosati (Anonim o'qish va yozish uchun ruxsat)
ALTER TABLE students ENABLE ROW LEVEL SECURITY;
ALTER TABLE homeworks ENABLE ROW LEVEL SECURITY;
ALTER TABLE chats ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Public access for students" ON students;
CREATE POLICY "Public access for students" ON students FOR ALL USING (true) WITH CHECK (true);

DROP POLICY IF EXISTS "Public access for homeworks" ON homeworks;
CREATE POLICY "Public access for homeworks" ON homeworks FOR ALL USING (true) WITH CHECK (true);

DROP POLICY IF EXISTS "Public access for chats" ON chats;
CREATE POLICY "Public access for chats" ON chats FOR ALL USING (true) WITH CHECK (true);

-- 5. Realtime sinxronizatsiyani yoqish
ALTER PUBLICATION supabase_realtime ADD TABLE students;
ALTER PUBLICATION supabase_realtime ADD TABLE homeworks;
ALTER PUBLICATION supabase_realtime ADD TABLE chats;
